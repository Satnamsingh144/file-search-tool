# Smart File Search Tool

A Python-based tool that searches files inside a folder quickly based on name or file type.

---

## 🚀 Features

- Search files by name keyword
- Filter files by extension (e.g. .pdf, .jpg)
- Recursively scans all subfolders
- Displays full file paths
- Simple and easy-to-use CLI interface

---

## 🛠️ Technologies Used

- Python
- os module

---

## ▶️ How to Run

1. Clone the repository:
   git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git

2. Navigate to the folder:
   cd YOUR_REPO_NAME

3. Run the script:
   python main.py

---

## 📌 Example

Enter folder path:
C:/Users/YourName/Documents

Enter keyword:
report

Enter extension:
.pdf

Output:
C:/Users/YourName/Documents/report1.pdf  
C:/Users/YourName/Documents/work/report2.pdf  

Total files found: 2
